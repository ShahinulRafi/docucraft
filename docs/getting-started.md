## Getting Started with Protocol

Welcome to Protocol! This guide will help you make your first API request.

### Prerequisites

Before starting, make sure you have:

- A Protocol developer account.
- An active application.
- A valid API key.
- Basic knowledge of HTTP requests.

### Your First API Request

You can test your API connection using the following endpoint:

`GET https://api.protocol.dev/v1/status`

A successful response will return your application status.

### Next Steps

Continue to the [Authentication](/authentication) guide to learn how to securely authenticate your requests.
