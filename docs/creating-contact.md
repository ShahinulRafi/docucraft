## Creating Your First Contact

This guide explains how to create a contact using the Protocol API.

### Step 1: Prepare Your Request

Prepare the contact information you want to store.

### Step 2: Send the Request

Send a POST request to:

`https://api.protocol.dev/v1/contacts`

Include your API key and contact information.

### Step 3: Check the Response

A successful request returns the newly created contact with its unique ID.

### Conclusion

You can now use this contact ID to retrieve or update the contact.
