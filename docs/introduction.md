## API Documentation

Use the Protocol API to access contacts, coversations, group messages, and more and seamlessly integrate your product into the workflows of dozens of devoted Protocol users.

### Getting Started

To get started, create a new application in your [devloper settings](/_dev-settings) , then read about how to make requests for the resources you need to access using our HTTP APIs or dedicated client SKDs. When your integration is ready to go live, publish it to our [integration directory](/integration-dir) to reach the Protocol community.
