## API Documentation

Use the Protocol API to access contacts, conversations, group messages, and more. Seamlessly integrate your product into the workflows of Protocol users.

### Getting Started

To get started, create a new application in your [developer settings](/dev-settings). Then learn how to make requests using our HTTP APIs.

When your integration is ready, publish it to our [integration directory](/integration-dir).
