## Sending Your First Message

Learn how to send messages through an existing Protocol conversation.

### Step 1: Find a Conversation

Retrieve an existing conversation ID using the Conversations API.

### Step 2: Prepare the Message

Create a message containing the conversation ID and message content.

### Step 3: Send the Message

Make a POST request to `/v1/messages`.

### Step 4: Verify Delivery

Check the response for the message ID and delivery status.
