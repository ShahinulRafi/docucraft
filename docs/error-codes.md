## API Error Codes

Protocol uses standard HTTP status codes to indicate request outcomes.

| Status Code | Meaning               |
| ----------- | --------------------- |
| 200         | Request successful    |
| 201         | Resource created      |
| 400         | Invalid request       |
| 401         | Unauthorized          |
| 403         | Forbidden             |
| 404         | Resource not found    |
| 429         | Rate limit exceeded   |
| 500         | Internal server error |

### Troubleshooting

Check the response body for additional error information. If the issue persists, contact Protocol support.
